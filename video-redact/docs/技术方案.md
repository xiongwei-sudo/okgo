# 视频打码技术方案

本地 GPU 上的视频脱敏：先按需增强，再检测人脸、车牌和敏感文字，跟踪后打码，最后用 ffmpeg 把原音轨嵌回去。部署在 AutoDL / SeetaCloud，不用容器。安装步骤见 [GPU部署安装说明.md](GPU部署安装说明.md)。

## 目标与边界

| 约定 | 做法 |
|------|------|
| 无容器 | 单机 Python / conda 或虚拟环境，不打 Docker 镜像 |
| 一卡一任务 | 内存队列只有 1 个 worker，同一时刻只占一张 GPU |
| 按需加载 | 人脸、车牌、OCR、增强都在任务开始时加载，结束卸载 |
| 运行位置 | 数据盘 `/root/autodl-tmp/video-redact`，不把权重和成片堆在系统盘 |
| 入口 | `cli.py` 与 FastAPI（默认端口 6006） |

上层 Astro 博客与本子项目分开构建。本目录不参与博客的 `npm` 流程。

## 主流水线

```
输入视频
  → 可选增强（稳像 → 低光 → 去噪 → 去糊 → 超分）
  → 检测（人脸 / 车牌 / OCR）
  → 简易跟踪（检测帧之间沿用框）
  → 打码（高斯 / 马赛克 / 纯色）
  → ffmpeg 回嵌音轨
  → 输出视频
```

实现在 `pipeline/pipeline.py`。检测步长由 `--stride` 控制，中间帧靠 `pipeline/track.py` 减轻闪烁。框会按 `margin` 略放大再打码。

## 检测与打码

| 目标 | 实现 | 缺权重时 |
|------|------|----------|
| 人脸 | 优先 MediaPipe；失败则 YuNet `weights/face_detection_yunet_2023mar.onnx` | YuNet 文件也不在则该检测器报错 |
| 车牌 | Ultralytics YOLO，`--device cuda:0`。文件名为 `plate_yolov8n.pt`、`yolov8n-plate.pt` 或 `license_plate_yolov8n.pt` | 颜色/轮廓启发式，并写 `weights/PLATE_WEIGHTS_PENDING.txt` |
| 敏感文字 | RapidOCR。只打身份证号、手机号（正则），不打全部文字 | 首次推理自行下载 det/rec |

打码三种模式：`gaussian`、`mosaic`、`solid`，强度由 `strength` 控制。

`scripts/download_weights.py` 拉取 YuNet，并按公开地址尝试车牌权重。OCR 不在这个脚本里下载。

## 增强 N1–N4

建议顺序：稳像 → 低光 → 去噪/去糊 → 超分，然后再打码。开关在 CLI（`--enhance` 及子项）和网页表单里。

| 编号 | 目标模型 | 当前 |
|------|----------|------|
| N1 | Real-ESRGAN（2x / 4x） | 【待补】。OpenCV 先放大再缩回原分辨率，避免编码器尺寸对不上 |
| N2 | Zero-DCE++ 低光；NAFNet 去噪 / 去糊 | 【待补】。分别降为 CLAHE、`fastNlMeans`、反锐化 |
| N3 | vidstab | 【待补】。降为 OpenCV 光流稳像 |
| N4 | BasicVSR++ 视频超分 / 修复 | 方案预留，代码尚未单独开关 |

权重放在 `weights/` 或 `weights/enhance/`。文件被发现时日志写「已发现但仍【待补】接入」，画面仍走 OpenCV。任务结束会清掉稳像状态。

## FastAPI 与队列

`web/app.py` 提供上传、进度和下载。页面与 API 同源，不启用 CORS。

- 上传先写到 `jobs/<id>/` 下的临时文件，`fsync` 后原子改名为 `input.*`，再 `queue.submit`。
- 进度字段包括排队、处理中、完成、失败和百分比。
- `pipeline/queue.py` 的线程池 `max_workers=1`，保证一卡一任务。
- 监听 `0.0.0.0:6006`，对应 AutoDL 自定义服务端口。

## 权重与 Git

`video-redact/.gitattributes` 把 `weights/*.pt`、`weights/*.onnx` 以及子目录中的同类文件标为 Git LFS。样片、任务输出、虚拟环境和 `*.engine` 不入库。没有现成的小 YuNet 文件时，用下载脚本在 GPU 机上拉取，不要把大二进制推进博客仓库。

## 分期

- M1：CLI 人脸打码
- M2：车牌、马赛克、ffmpeg 音轨
- M3：OCR 敏感过滤、简易跟踪
- M4：单卡队列、按需加载、网页增强开关（进行中）
- N1–N4：专用权重接入；在此之前 OpenCV 降级可先上线
